# Webfem 拼豆图纸生成器

Vue 3 + Vite 的拼豆图纸生成器。

## 功能

- 选择拼豆盘尺寸：8–200 格。
- 导入 JPG / PNG / WEBP 图片并自动转换到 MARD 221 色。
- 默认直接进入「修改图片」，提供透明空白底板。
- 「底板颜色」与「调色盘」共用 MARD 色号，底板额外提供透明选项。
- 用户实际放置的拼豆与底板分离：修改底板颜色不会覆盖已放置拼豆。
- 可显示坐标与格内色号。
- 左侧保留参考图片与颜色使用数量。
- 导出漂亮的 PNG 图纸，并包含颜色方块、MARD 色号和数量。
- 导出 PDF 图纸，PDF 与 PNG 使用相同的版式。

## 启动

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
